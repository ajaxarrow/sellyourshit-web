## Profile

## Appearance
Again, pretty straightforward kind of stuffs. I think I spent more time typing this than I ever would if I just explain what does this do so that pretty somes up how I really emphasize how easy this is

## Manage List
So this items are the things that appear across the applications, the brands, garment types, sales channels and customers. All have the same logic, just click it, add some stuff, you can edit the text and also delete it. There are some pre added fields like in brands and types and you can edit all of them.

## Data
So sellyoshit is a fully offline application (except if you submit a ticket and docs which will be discussed next). The founder of this doesn't have the budget to make this a cloud based app so all the data lives in your phone. If you erase the data so bye bye inventory and all your input data. But thankfully we do have solutions for that
### Backup & Restore
Click this item and you will be redirected to another page
Backup Now -> clicking backup now will backup all data, from profile, inventory and your sales, all that stuff, including the images. It will be save into a json file into your selected app
Restore from backup: this will restore your data from a selected json backup file

### Reset Data
I don't know the reason for you resetting your data, you could've just go to settings then clear storage but in here you can reset your data. Sellyoshit gives you a selection of what items to reset tho
